# Distributed RPC and Messaging Systems

A Go-based distributed-systems project that separates authentication and file services and studies communication through RPC and messaging patterns.

## Structure

- `auth-vm/`: authentication service and subscriber component.
- `file-vm/`: file-serving component with small sample files and images.
- `rpc-study/`: supporting RPC study material.
- `assignment.pdf`: original assignment specification.

The repository retains the source code and small inputs needed to understand and run the services. Submission screenshots, the packaged ZIP, and the final report are intentionally excluded.

## Run

Install Go and follow the component-level README files. Run the services in separate terminals or virtual machines as described in the assignment.
